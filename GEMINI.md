# Project: Personal Homepage

## Directory Overview

This directory contains a simple, static personal homepage for a marketer. The content is in Korean and describes a professional focused on data-driven marketing, human psychology, and branding. The entire page is a single `index.html` file with embedded CSS.

## Key Files

*   `index.html`: The main and only file for the website. It contains the HTML structure, content, and all the CSS styles for the page.
*   `README.md`: Currently empty, but can be used for more detailed project information.

## Usage

This is a static website. To view it, simply open the `index.html` file in any web browser.

### Running the Project

No build process or special commands are needed.

```bash
# On macOS
open index.html

# On Windows
start index.html

# On Linux
xdg-open index.html
```

## Development Conventions

*   All styles are currently embedded within a `<style>` tag in the `index.html` file.
*   The project uses CSS variables for theming (colors, gradients, etc.).
*   The layout is responsive and uses CSS Grid and Flexbox.
